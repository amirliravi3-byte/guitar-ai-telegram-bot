# Third-party components

This project orchestrates third-party open-source libraries; it does not vendor their source code.

- Spotify Basic Pitch — audio-to-MIDI transcription — see its upstream repository/license.
- PyGuitarPro — GP3/GP4/GP5 read/write — LGPL-3.0 upstream.
- librosa — audio/music analysis — see upstream license.
- FFmpeg — media conversion — system package on GitHub runner; see upstream licensing.
- NumPy / SciPy / matplotlib / pretty_midi / mido / requests / soundfile — installed from PyPI under their respective licenses.

The generated orchestration/source files in this repository may be used and modified under the MIT license included with the project. Third-party dependencies remain governed by their own licenses.
